# La Noche MVP

Web party game: "Tus amigos son el juego".

## Flujo
1. Host crea sala y comparte código.
2. Invitados entran sin cuenta.
3. Todos cargan tres secretos, una verdad, una mentira y tres votos de mayoría.
4. El servidor genera rondas automáticas.
5. Todos votan desde el celular.
6. El host revela y avanza; hay puntaje y ranking final.

## Stack
- Node.js + Express
- PostgreSQL
- HTML/CSS/JS sin framework
- Deploy pensado para Render

## Variables
- DATABASE_URL
- PORT (Render la define automáticamente)
